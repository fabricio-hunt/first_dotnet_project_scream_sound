# C# and .NET — Getting Started Course

Personal notes and code produced while following an introductory C# and .NET course, covering environment setup, core language fundamentals, and small practice exercises using lists and dictionaries.

## What this course covers

- Installing and configuring the development environment across different operating systems
- Writing a first C# program and understanding the concept of strong typing
- Exploring the C# ecosystem, including documentation and useful resources (Stack Overflow, Office 2019)
- Building functions to display a main menu and register bands in lists and dictionaries
- Evaluating bands and calculating averages based on registered data
